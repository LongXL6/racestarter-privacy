Microphone & Speech Recognition

RaceStarter asks for microphone access for three optional features:

  • Reaction timing — hearing your motors spool up after the GO signal to measure your launch reaction (and to flag a jump start when they spool up early)
  • Lap timing — hearing your drone pass the gate the phone is placed beside
  • Hands-free voice start — recognizing a spoken start keyword

Audio is analyzed live in memory as it arrives and is discarded immediately. RaceStarter never writes a recording to disk, never keeps an audio buffer after a run, and never transmits audio anywhere. The only mic-derived results that are ever saved are the two the reaction timer produces — a reaction time in milliseconds and a jump-start flag — which go into the local history described below. Lap times are held in memory for the current run only and are cleared when you start the next run or leave the lap timer; they are never written to storage. A recognized start keyword only fires the start; the recognized speech itself is never stored.

Hands-free voice start additionally uses Apple's Speech framework with on-device recognition required, so spoken audio is never sent to Apple's servers or to us. If your device or language does not support on-device recognition, the App tells you so and the feature stays off — it never silently falls back to server-based recognition.

All three features are off unless you turn them on, and the App works fully without granting microphone or speech-recognition access.

Local Storage

Everything RaceStarter saves stays inside the App's own sandbox on your device:

  • Preferences — language, sound style, countdown and random-delay settings, and the on/off state of features such as the reaction timer, voice coach, GO haptics, drill sets and session goals. Stored with standard iOS UserDefaults.
  • Race history (optional, and you can turn it off or clear it at any time) — stored as a JSON file in the App's Application Support directory (Application Support/RaceStarter/history.json). Each entry records the start mode, the countdown length or random delay range, the sound style, a timestamp, and — when the reaction timer is on — the measured reaction time in milliseconds and a jump-start flag; a start fired inside a drill set also carries that set's identifier. Lap times are never part of an entry.
  • Custom sounds — audio files you import are copied into the App's Documents directory.

This data never leaves your device and is not accessible to us or any third party. As of version 2.0 the App no longer uses iCloud synchronization of any kind; exporting your history to CSV or JSON happens only when you tap Export and choose where the file goes.

Network Access

RaceStarter operates entirely offline. The App does not make any network requests and does not require an internet connection to function.
